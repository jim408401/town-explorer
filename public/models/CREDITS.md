# Model credits

The game can optionally load the GLB models below from this folder. They come from
[Three.js Assets](https://threejsassets.com/) and are all marked **Free** under the
**Free Commercial License** (https://threejsassets.com/license).

That licence allows using the models in games and websites without attribution, but
forbids sharing or redistributing the model files themselves. The `.glb` files are
therefore **not committed** (see `.gitignore`). To use them locally, sign in to
threejsassets.com, download each GLB and save it here under the file name shown.
Any model that is missing is replaced by a procedural stand-in.
